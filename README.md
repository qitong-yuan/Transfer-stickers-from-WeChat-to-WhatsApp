# Transfer-stickers-from-WeChat-to-WhatsApp

把微信表情包变成 WhatsApp 贴纸。双击即可。

WhatsApp 的贴纸对格式很挑：必须是 512×512 的 webp，静态图不能超过 100KB，动态图不能超过 500KB。微信里存的表情是 gif、png、jpg 混着来，尺寸也乱七八糟，直接传过去用不了。这个小工具就是把中间这段脏活干掉。

## 它做什么

给它一堆图片，它会挨个处理：等比缩放到 512×512、居中、四周补透明像素，动图的每一帧都保住不会变成静态图，然后自动往下压质量直到塞进 WhatsApp 的体积限制里。最后打包成一个 `.wastickers` 文件，用 Sticker Maker 打开就能整包导进 WhatsApp，不用一张张点着添加。

支持 gif / png / jpg / jpeg / webp / bmp，动图静图都行。

## 它不做什么

**它不会自动从微信里抓表情。** 表情要你自己挑好、自己存出来。

我原本写过自动扫描微信缓存目录的版本，但微信 4.x 把本地缓存加密了，解出来大半是打不开的乱码，而且分不清哪些是你自己收藏的、哪些只是聊天里别人发过被缓存下来的。与其猜，不如你自己挑——想要哪个存哪个，所见即所得，五分钟的事。

## 怎么用

需要 Windows + Python 3.8 以上，以及 Pillow 库：

```
pip install pillow
```

然后：

1. 把 `表情转换.py` 和 `点我转换.bat` 放进同一个文件夹
2. 双击 `点我转换.bat`，它会自动建出一个 `1_把表情放这里` 文件夹
3. 打开电脑版微信，把想要的表情发给「文件传输助手」，在聊天窗口里对着表情**右键 → 另存为**，存进那个文件夹（也可以直接用鼠标把表情拖进去，更快）
4. 再双击一次 `点我转换.bat`

转好的东西在 `2_转换结果` 里：`.wastickers` 是打包好的整包，`贴纸图片` 文件夹里是单张的 webp。

## 导进 WhatsApp

手机上装一个 **Sticker Maker** 或 **Sticker.ly**，然后两条路选一条：

省事的做法是把 `.wastickers` 文件传到手机，用 Sticker Maker 打开它，整包一次性导入。

如果那条路不通，就把 `贴纸图片` 里的 webp 传到手机，在 Sticker Maker 里新建一个贴纸包，批量选中它们，再点 Add to WhatsApp。

WhatsApp 规定一个包最少 3 张、最多 30 张。超过 30 张的话脚本会自动拆成好几包。

## 改包名和作者名

打开 `表情转换.py`，最上面有两行：

```python
PACK_TITLE = "我的微信表情"
PACK_AUTHOR = "your name"
```

改成你想要的就行，这两个名字会显示在 WhatsApp 的贴纸包信息里。

## 常见问题

**双击 bat 一闪就没了**：多半是没装 Python 或者没勾 Add to PATH。重装 Python 时勾上那个选项，或者在命令行里直接跑 `python 表情转换.py` 看报什么错。

**提示缺少 Pillow**：跑 `pip install pillow`。

**动图导进去变成静态的**：确认你存出来的是 `.gif` 而不是被微信转成了 `.png`。另存为的时候留意一下后缀。

**转出来的动图还是超过 500KB**：脚本会自动降质量、抽帧、缩尺寸去压，但特别长的动图可能压不下来。剪短一点再试。

**背景变成黑色或白色**：源图本身没有透明通道。jpg 格式不支持透明，这种情况下只能接受，或者找张 png/gif 版本的。
